Graduate Course Assignments

This repository is created for graduate students to submit their individual course projects through GitHub Pull Requests.

Submission Instructions

Each student must:

Fork this repository to their own GitHub account.

Create a folder under projects/ using their name and surname.

Upload their project files and source code.

Include a README.md file explaining the project.

Commit and push their changes to their fork.

Open a Pull Request to the original repository's main branch.

Required Project Documentation

Each project must include:

Student name

Project title

Project description and objectives

Technologies and programming languages used

Installation and execution instructions

Results and screenshots (if applicable)

References (if applicable)

Important Rules

Each student must submit their own project.

Do not modify or delete another student's files.

Do not upload passwords, API keys, or sensitive information.

The Pull Request title must follow this format:

Student Name - Project Title

Projects will be evaluated through Pull Request reviews.

Students must address requested changes before final approval.

Note: Opening a Pull Request does not mean the project has been approved.
