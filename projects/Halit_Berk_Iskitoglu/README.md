# CICIoMT2024: Explainable Device-Aware Attack Risk Assessment and Prioritization for IoMT Networks

## Student Information

- Student Name: Halit Berk İskitoğlu

## Project Description

This project aims to develop an explainable machine learning-based framework for attack detection and device-aware risk prioritization in IoMT networks.

## Objectives

- Detect malicious network traffic using machine learning.
- Estimate attack probabilities.
- Explain model predictions using SHAP.
- Identify IoMT devices associated with network traffic.
- Prioritize devices according to their potential security risk.
